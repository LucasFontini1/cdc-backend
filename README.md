# CDC — Backend

Código backend do projeto CDC, estruturado com Django e Django REST Framework.

## Tecnologias

- Python
- Django
- Django REST Framework
- Gerenciamento de dependências e configurações conforme os arquivos do projeto

## Como executar

Consulte os arquivos de configuração e dependências Python deste repositório para preparar o ambiente e iniciar o servidor. Defina as variáveis de ambiente necessárias localmente e não publique credenciais.

## Contexto

Repositório de estudos e projetos de desenvolvimento. Para conhecer os recursos efetivamente implementados, consulte os arquivos do código-fonte.
